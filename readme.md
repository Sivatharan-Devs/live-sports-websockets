### 4. create a new folder(src)

```bash
mkdir src

```

### 5. inside src folder create index.js file

```bash
cd src
touch index.js
cd ..

```

### 6. "Set up a simple express server in javascript that listen on port 8000, uses json middleware, has root get route that returns a short message, and logs URL when the server starts." (index.js)

```javascript
import express from "express";

const app = express();
const port = 8000;

app.use(express.json());

app.get("/", (req, res) => {
  res.send("Hello from Express server!");
});

app.listen(port, () => {
  console.log(`Server is running at http://localhost:${port}`);
});
```

### 7. Add script to package.json file

```json
"scripts": {
    "dev": "node --watch src/index.js",
    "start": "node src/index.js"
  },
```

and run it using :

```bash
npm run dev
```

then open it on [Open the server](http://localhost:8000)
